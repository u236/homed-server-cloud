# HOMEd Cloud Server

Сервер для интеграции устройств HOMEd с Умным Домом Яндекса

## Однопользовательский режим

Сервер может работать в режиме одиночного пользователя без изспользования Telegram-бота. Для этого в конфигурационный файл нужно добавить секцию `[user]`:

```ini
[user]
name=
password=
token=
```

* `name` и `password` — логин и пароль для связывания аккаунтов
* `token` — токен клиента в HEX-формате (его же нужно указать в параметре `cloud/token` конфигурационного файла клиента)
